# Documents légaux

Ce dossier contient les documents légaux publics de la suite **Grimoire**.

Chaque application dispose de son propre sous-dossier afin de conserver des URLs stables et explicites.

## Grimoire Inventaire / Grimoire Inventory

- Politique de confidentialité : [`grimoire-bourse/privacy-policy.md`](grimoire-bourse/privacy-policy.md)
- URL publique stable : https://thurtwings.github.io/Grimoire_Administratif/legal/grimoire-bourse/privacy-policy.html
- Contact : **thurtwings.games@gmail.com**

Le dossier `grimoire-bourse` conserve son nom historique pour compatibilité avec les URLs déjà publiées. Le nom visible de l'application est **Grimoire Inventaire / Grimoire Inventory**.

Les futures applications de la suite devront suivre la même structure, par exemple :

```text
legal/
  grimoire-mj/
    privacy-policy.md
  grimoire-pj/
    privacy-policy.md
```

Ne pas créer de politique vide : chaque document doit refléter le comportement réel de l'application concernée.
